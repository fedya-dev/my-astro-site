## How to add an article

Create a new `.md` file in `src/content/blog/`. Its filename becomes part of the article URL. Fill in the required frontmatter fields and write the body in Markdown.

## Publishing

Posts with `draft: true` are excluded from the generated site. When ready, set it to `false` and run `npm run build`.
